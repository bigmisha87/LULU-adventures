# LULU ADVENTURES

אתר קונספט בעברית למשחק פלטפורמה דו־ממדי עם לולו ומשה בתל אביב.

קובצי האתר נמצאים בתיקיית `dist`, כולל התמונות, האנימציות וסרטון הקונספט. הסרטון בראש האתר מתחיל עם סאונד רק אחרי לחיצה על PLAY.

## תצוגה מקומית

נדרש Node.js. מתוך תיקיית המאגר:

```sh
node preview.mjs
```

פותחים את http://127.0.0.1:4173.

## בדיקת הקבצים

```sh
node check-site.mjs
```

## אחסון

אפשר להגיש את תיקיית `dist` בכל שירות לאחסון אתרים סטטיים. אין צורך בתהליך build או בהתקנת חבילות.

חומרי המקור והסקיצות נשמרים בנפרד ואינם חלק מהמאגר.
